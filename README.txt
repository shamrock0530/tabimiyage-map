旅みやげMAP Ver.2.0（無料・iPhone向けPWA）

【使い方】
1. このフォルダの全ファイルを、HTTPSに対応した静的Webホスティングへアップロードしてください。
2. iPhoneのSafariで公開URLを開き、共有メニューから「ホーム画面に追加」してください。
3. アプリ内の「旅行を追加」「商品を追加」から登録できます。
4. 「その他」→「バックアップ保存」で、写真を含むJSONを定期的に保存してください。

【注意】
- ZIPファイルをiPhoneに置いただけではPWAとしてインストールできません。HTTPS公開が必要です。
- 保存はiPhoneのSafariのIndexedDBです。ブラウザデータ削除や端末故障に備え、必ずバックアップしてください。
- Googleマップ営業時間の自動取得は行いません。店舗情報の確認ボタンで最新情報を確認してください。
- AI提案はChatGPTのWebサイトに移動します。回答の自動取り込みは行いません。
- 写真はJPEGへ縮小して保存します。大量の写真は端末の保存容量に影響します。
- Google Maps / ChatGPT はネット接続が必要です。
- このアプリにはAPIキー・課金サービス・分析ツールは含まれません。
- Googleマップ検索は店名検索であり、検索結果が目的店舗と一致するか確認してください。
